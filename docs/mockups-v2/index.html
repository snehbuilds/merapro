Every Phase 1 screen, in light and dark.

Static HTML, no build step and no dependencies — open any file directly. The design system lives in one stylesheet and is written to port into Next.js, Tailwind and shadcn/ui without redrawing anything. Press ⌘K anywhere to jump between screens, and use the toggle above to switch themes.

All content is demonstration data. Accounts, handles, metrics and post text are synthetic. The worked example — a PostgreSQL 18 story going to four accounts in the Tech News group — is the same one used throughout the architecture docs.

Design system

v2 — a dispatch ledger. Warm paper and black ink, one verdigris action colour, an always-dark control rail that keeps navigation and the kill switch apart from the work. Condensed IBM Plex labels read like column heads on a form; IBM Plex Mono carries machine data — hashes, versions, IDs, timestamps, costs. Each post set draws a branch to its per-account variants, and approval proof is a perforated receipt.
